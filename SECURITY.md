# Security Policy

Sansis Daily Officer is an internal Sansis Wedding application.

## Repository Visibility
Keep this repository **Private**.

## Never Commit
- Plain-text Employee passwords
- Plain-text Administrator passwords
- Temporary passwords
- Login session tokens
- Employee personal-data exports
- Google credentials or API secrets
- Service account keys
- Private production data

## Password Handling
Use only the application's password hashing mechanism. Temporary passwords generated by the Administrator interface should be provided directly to the intended Employee and must not be committed.

## Production Data
Production Google Sheets and Google Drive data should remain outside GitHub.
